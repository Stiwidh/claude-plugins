# Plugins de Claude de la comunidad Protocolo EVA

Los agentes de IA de la comunidad, para que los tengas en tu Claude y se actualicen solos cada vez que los mejoramos.

## Qué incluye

| Plugin | Para qué te sirve |
|---|---|
| **Stella** | Estrategia de contenido: pilares, embudo y calendario. Decide qué publicar y cuándo. |
| **Vega** | Guiones de vídeo corto (Reels, TikTok, Shorts) listos para grabar. |
| **Aria** | Secuencias de Instagram Stories que conectan y venden. |
| **Lyra** | Prompts de imagen y vídeo con IA, adaptados a cada herramienta. |

Trabajan en equipo: Stella planifica y Vega, Aria y Lyra ejecutan. Todos se adaptan a tu marca.

## Antes de empezar

- Necesitas un plan de pago de Claude (Pro o Max). Con el plan gratuito no se pueden instalar plugins.
- Si ya instalaste alguno subiendo un archivo `.zip`, quítalo antes para no tenerlo repetido.

## Instalación (solo la primera vez)

1. Abre la app de Claude en tu ordenador. En la barra lateral, **Customize** → **Plugins**.
2. Elige **Agregar desde un repositorio**.
3. Pega esto y confirma:

   ```
   Stiwidh/claude-plugins
   ```

4. Aparecerá el catálogo **protocolo-eva**. Instala los plugins que quieras.
5. Activa la **sincronización automática** de ese catálogo. Así cada mejora te llega sola, sin volver a instalar nada.

### Si usas Claude Code

```bash
/plugin marketplace add Stiwidh/claude-plugins
/plugin install stella@protocolo-eva
```

Cambia `stella` por `vega`, `aria` o `lyra` para instalar los demás.

## Dónde funcionan

- **App de escritorio (Cowork y Code):** todo, incluidos los agentes especialistas de cada plugin.
- **Chat (web y app):** las habilidades sí; los agentes especialistas solo se ejecutan en Cowork y Code.

## Si algo no funciona

Avisa en la comunidad de Protocolo EVA y lo revisamos.
