# Secuencia MARCA (Stories)

Genera secuencias tipo MARCA: 5-6 slides cuyo objetivo es generar conexión y autoridad. **Nunca incluyen CTA de venta** — solo interacción algorítmica (encuesta, reacción, cajita preguntas).

## Instructions

### Paso 1 — Inputs obligatorios

- **Tema central:** valor / posicionamiento / detrás de cámaras / historia personal del proyecto / opinión polémica / lección aprendida
- **Tipo de interacción objetivo:** encuesta / reacción / respuesta a story / cajita de preguntas
- **Material disponible:** fotos, vídeos, screenshots
- **Día de la semana:** afecta tono (lunes inspirador, miércoles autoridad técnica, viernes personal)

### Paso 2 — Tipos de historia MARCA según calendario

| Tipo | Función | Cuándo |
|---|---|---|
| **Storytelling personal del proyecto** | Conexión emocional | Lunes / viernes |
| **Autoridad técnica simplificada** | Posicionamiento como hermana mayor techie | Miércoles |
| **Detrás de cámaras de creación de avatares** | Tech-warmth + transparencia IA | Cualquier día |
| **Crítica al gurú / industria** | Diferenciación clara | Cuando hay polémica activa |
| **Predicción / opinión** | Engagement, debate | Cuando hay tendencia tech |
| **Lección de una alumna** | Social proof orgánico | Tras testimonio nuevo |

### Paso 3 — Estructura 5-6 slides

| Slide | Bloque | Función |
|---|---|---|
| 1 | OPENER | Engancha — pregunta directa, dato sorprendente, declaración polémica |
| 2 | OPENER (opcional) | Si el tema es complejo, dimensionar |
| 3-4 | CONTENIDO | Desarrollar la idea con metáforas EVA (Jardín, Génesis, morder la manzana) |
| 5-6 | INTERACCIÓN | **Sticker de interacción** (NO CTA venta) — encuesta, reacción, cajita preguntas |

### Paso 4 — Reglas específicas MARCA

1. **CERO menciones de producto/oferta** — esto NO vende, conecta.
2. **Sticker interacción obligatorio** en último slide — algoritmo IG necesita señal positiva.
3. **Voz de marca aplicada** (ver skill `audience-narrative`):
 - "Detrás de cámaras" = proceso de creación de avatares (no rutinas humanas falsas)
 - "Lifestyle" = demostrar facturación con avatar (no copas/yates)
 - "Vulnerabilidad" = honestidad sobre IA (lo que puede y no puede)
4. **Firma "Eva 🧬"** y hilo rojo aplican igual que en VENTA.

### Paso 5 — Herramientas de interacción

| Sticker | Cuándo usar |
|---|---|
| **Encuesta/Poll** | Validar opinión, hacer elegir, pedir apoyo |
| **Cajita de preguntas** | Q&A estratégico, "¿Qué te frena de empezar?" |
| **Likes/Reacciones** | "Si piensas igual, dale 🔴" |
| **Respuesta a story** | "¿Cuál es tu mayor miedo a mostrar la cara?" — genera replies (señal algorítmica fuerte) |
| **Countdown** | Eventos, no ventas (próxima sesión live, etc.) |

### Paso 6 — Output (formato obligatorio)

```
## MARCA — [Tema]

### Slide 1 — OPENER
- **Formato:** [foto+texto / vídeo / fondo oscuro]
- **Visual:** [descripción]
- **Texto:** "[texto exacto]"
- **Sticker/CTA:** [Encuesta / Reacción / Ninguno]

(slides 2-N)

### Slide 5 — INTERACCIÓN
- **Formato:** [...]
- **Visual:** [...]
- **Texto:** "[texto pregunta]"
- **Sticker:** [Tipo de sticker — encuesta/cajita/reacción/respuesta-story]

📌 **Notas de publicación:**
- Mejor hora sugerida: [si aplica]
- Material necesario: [...]
- Tipo interacción: [encuesta/cajita/reacción/respuesta]
- Hilo rojo aplicado: [elemento rojo]
- Firma: "Eva 🧬" en slide [N]
```

### Paso 7 — Pre-entrega checklist

- [ ] CERO mención de producto, oferta o link
- [ ] Sticker de interacción presente y específico
- [ ] Hilo rojo presente
- [ ] Firma "Eva 🧬"
- [ ] Identidad voz de marca respetada (voz de marca consistente)
- [ ] Variación de formato entre slides
- [ ] Tono según día (lunes inspirador / miércoles autoridad / viernes personal)
