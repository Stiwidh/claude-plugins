# Solo el guion

El plano del vídeo, para revisarlo antes de gastar nada.

## Pasos

1. ¿Marca o anuncio? (pregunto si no está claro).
2. El `storyboard-artist` escribe las escenas con la voz, lo que se ve y la duración.
3. 3 títulos (en contenido de marca, cada uno descarta a quien no es el cliente) + idea de miniatura.

## Lo que recibes

El guion por escenas + títulos + miniatura, listo para producir cuando digas.
