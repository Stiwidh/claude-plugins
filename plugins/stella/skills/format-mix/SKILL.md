# Format Mix

Cada formato hace un trabajo distinto en el embudo. Usar solo uno es desaprovechar. Fuente: §5 del Master Book (`skills/strategy-method/references/strategy_method.md`).

## Tabla de formatos

| Formato | Fortaleza | Trabajo | Embudo |
|---|---|---|---|
| **Reel / vídeo corto** | Alcance (gente nueva) | Atraer, enseñar, posicionar | TOFU (y MOFU/BOFU con guion) |
| **Carrusel** | Guardado, profundidad | Enseñar en detalle, listas | TOFU/MOFU |
| **Stories** | Cercanía diaria, conversión | Conectar, vender, interactuar | MOFU/BOFU |
| **Directo / live** | Autoridad, confianza profunda | Relación, dudas, vender en caliente | MOFU/BOFU |
| **Post foto + copy** | Marca, mensaje | Valores, historias, autoridad | MOFU |

## Lecturas clave
- **El alcance vive en el Reel** → tu motor de TOFU (guion → plugin `vega`).
- **La conversión vive en stories/directos** → tu canal de MOFU/BOFU (stories → plugin `aria`).
- **El guardado vive en el carrusel** → valor que se archiva.
- **El plan combina:** Reels para entrar, carruseles para profundizar, stories para convertir.
