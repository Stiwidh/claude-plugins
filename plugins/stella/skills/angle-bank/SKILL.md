# Angle Bank

No necesitas más temas: de cada **pilar** salen decenas de **ángulos**. Fuente: §7 y §3 del Master Book (`skills/strategy-method/references/strategy_method.md`).

## El proceso
1. **Toma un pilar** (ej. "vender sin sentirte vendedora").
2. **Explótalo en ángulos** cruzando: dolor/deseo concreto + nivel de consciencia (Schwartz) + formato. Cada combinación es una pieza distinta.
3. **Reparte por el embudo**: unos atraen (TOFU), otros nutren (MOFU), otros venden (BOFU).

## Reglas
- **Del problema, no del producto.**
- **Repartidos por el embudo** (no todos TOFU ni todos BOFU).
- **Sin repetición** — cambia perspectiva/enfoque/formato.
- El **detalle específico ES el ángulo** (genérico = tópico; especificidad que descarta).

## Output
```
## Ángulos del pilar: [pilar]
| # | Ángulo (con detalle específico) | Consciencia | Embudo | Formato |
(8-12 filas repartidas por el embudo)
```
Cada ángulo queda listo para `vega` (guion) o `aria` (story).

## Cross-skill
- Lotes grandes de ángulos → sub-agent `angle-generator`.
- Escribir el guion del ángulo → plugin `vega`.
