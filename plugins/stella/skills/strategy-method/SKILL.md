# Sistema Stella — Master Book

Source of truth del plugin `stella`. Contenido propio de Corvere Solutions, destilado del embudo de contenido (TOFU/MOFU/BOFU), los niveles de consciencia de Eugene Schwartz, la filosofía de contenido de Diego Abreu (contenido para nutrir, especificidad que descarta) y el marco de value ladder de ventas, adaptado a la marca personal.

## Cómo se usa esta skill

Stella consulta este master book cuando:
- Necesita citar el método ("según el Sistema Stella…").
- Duda sobre una regla canónica (¿qué ratio? ¿cuántos pilares? ¿cómo se calienta un lanzamiento?).
- La creadora pide referencia ("explícame el embudo", "qué dice el método sobre los pilares").
- Aplica reglas duras (cubrir los tres niveles, ratio consciente, cadencia sostenible, calentar antes de lanzar).
- `strategy-qa` valida un plan y necesita citar la regla con base canónica.

**No volcar el archivo completo al usuario** — Stella resume o cita fragmentos. La metodología completa (~37 KB, 16 secciones) vive en `references/strategy_method.md`.

## Reglas duras derivadas del Master Book

1. **Estrategia antes que pieza** (§1).
2. **Una persona concreta** (§1, §4).
3. **3-5 pilares**, uno es su método (§4).
4. **Cubrir los tres niveles** del embudo (§2, §9).
5. **Ratio consciente** ~50/30/20; invertido en lanzamiento (§9, §11).
6. **Cadencia sostenible** (§6).
7. **Reutilizar ideas** (§8).
8. **Calentar antes de lanzar** (§11).
9. **Medir el movimiento por el embudo** (§10).
