# Content Calendar

El calendario balancea **dos ejes a la vez**: pilares (que no sea siempre el mismo tema) y embudo (mezcla TOFU/MOFU/BOFU). Fuente: §6 y §11 del Master Book (`skills/strategy-method/references/strategy_method.md`).

## Cadencia sostenible
Más vale **3 piezas buenas/semana siempre** que 7 a medias y luego el abandono. Referencia:
- Feed (Reels/carruseles): 3-5/semana.
- Stories: casi a diario.
- Directo: 1 cada 1-2 semanas (opcional).
Elige el número que puedas mantener **6 meses**.

## Cómo se distribuye
- **Eje pilares:** rota (no siete piezas del mismo tema).
- **Eje embudo:** cada semana mezcla TOFU/MOFU/BOFU con el ratio (§9).
- **Ritmo del mes:** semanas 1-3 construir (TOFU/MOFU), semana 4 concentrar BOFU (o semana de lanzamiento, §11).

## Output
```
## Calendario — [periodo]
Cadencia: [piezas/semana] · Ratio: [X/Y/Z]
[Día] — [Formato] · [Pilar] · [nivel] — [ángulo] → ejecuta: [Vega/Aria/Lyra]
Nota de reutilización: [qué idea se estira]
```
