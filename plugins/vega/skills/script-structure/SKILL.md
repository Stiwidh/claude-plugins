# Script Structure

El esqueleto que funciona para casi cualquier Reel de valor. No es rígido: es la lógica de tensión → alivio que mantiene la curva alta. Fuente: §6 del Master Book (`skills/viral-method/references/viral_method.md`).

## El esqueleto

```
1. HOOK (0-3s)             → abre la brecha, texto gigante, un solo bucle
2. CONTEXTO/TENSIÓN (3-8s) → por qué importa AHORA; agita el problema (NO "ubicar")
3. VALOR/DESARROLLO        → la enseñanza/historia/demostración, con bucles encadenados
4. PAYOFF                  → cierras el bucle del hook; el "ajá"
5. CTA (una acción)        → un solo paso siguiente, suave
```

## Instructions

### Paso 1 — Hook
De `hook-formulas` / `hook-architect`. Las 3 capas.

### Paso 2 — Contexto/tensión (el error de la mayoría)
Estos segundos son para **agitar**, no para presentarse. No expliques quién eres ni de qué va el canal: sube la apuesta del hook. La empatía ("he pasado por ahí") compra permiso para el resto.

### Paso 3 — Valor/desarrollo
El cuerpo. **Un solo takeaway.** Cada frase empuja a la siguiente; bucles pequeños encadenados (skill `retention-curve`). Si hay tres ideas, son tres vídeos.

### Paso 4 — Payoff
Cierra el bucle del hook. Es el "ajá" que hace ver el vídeo entero.

### Paso 5 — CTA
Uno solo, coherente con el nivel de embudo (skill `cta-soft-design`).

## Duración (§6)
- **15-45s** la mayoría.
- Hasta **60-90s** solo si es storytime o tutorial que lo justifica.
- La duración no es meta: es el tiempo que la idea necesita, ni un segundo más.
