# Sistema Vega — Master Book

Source of truth del plugin `vega`. Contenido propio de Corvere Solutions, destilado de los referentes duros del short-form (Hormozi / Dynamic Minimalism, MrBeast, Ali Abdaal), del copywriting de respuesta directa (Schwartz, Sugarman) y de la especificidad de Diego Abreu, adaptado a la marca personal.

## Cómo se usa esta skill

Vega consulta este master book cuando:
- Necesita citar el método ("según el Sistema Vega…").
- Duda sobre una regla canónica (¿cuánto dura el hook? ¿qué familia de hook? ¿cómo se tapa un valle?).
- La creadora pide referencia explícita ("explícame por qué la gente hace scroll", "qué dice el método sobre el CTA").
- Aplica reglas duras (un takeaway, un CTA, especificidad que descarta, payoff que cierra el bucle).
- `viral-qa` valida un guion y necesita citar la regla violada con base canónica.

**No volcar el archivo completo al usuario** — Vega resume, referencia o cita fragmentos. La metodología completa (~37 KB, 19 secciones) vive en `references/viral_method.md`.

## Reglas duras derivadas del Master Book

1. **El hook es sagrado** (§4) — se entiende sin sonido, abre brecha en ≤8 palabras.
2. **Un solo takeaway** (§6) por vídeo.
3. **Específico hasta descartar** (§3) — si lo dice cualquiera del nicho, se reescribe.
4. **El payoff cierra el bucle del hook** (§6) — sin cierre no hay completion.
5. **Un solo CTA** (§11), suave, coherente con el embudo.
6. **Escrito para ser hablado** (§10).
7. **Un vídeo, un nivel de embudo** (§12).
8. **Cero purple prose / coach motivacional / datos inventados** (§14).
