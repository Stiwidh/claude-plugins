# CTA Soft Design

El cierre pide **una** acción, no cinco. Diluir el CTA es no tener CTA. Fuente: §11 y §12 del Master Book (`skills/viral-method/references/viral_method.md`).

## Reglas

1. **Un solo CTA por vídeo.** Elige uno: guardar, seguir, comentar una palabra, ir al link. Nunca la lista entera.
2. **El CTA según el trabajo del vídeo (embudo):**
   - **TOFU / educativo** → **guardar** ("guárdalo para cuando lo necesites") o seguir.
   - **MOFU / conexión** → **comentar** ("¿te ha pasado? cuéntamelo").
   - **BOFU / venta** → **la acción concreta** (comentar una palabra, ir al link).
3. **Comentario/palabra > link seco.** "Comenta VEGA y te mando la guía" genera interacción dentro de la app (que el algoritmo premia) y captura contacto. El "link en bio" saca a la gente de la app y se penaliza.
4. **Sin súplicas ni coach motivacional.** El CTA es una invitación clara, no una mendicidad ("¡porfa dale like!"). Dilo una vez, con naturalidad, y calla.

## Output
```
CTA: [la única acción]
Formulación: "[cómo se dice en el guion]"
Nivel de embudo: [TOFU/MOFU/BOFU] → coherente ✓
```
